Mi aplicación

Proyecto creado con silence new. Las páginas están en web/; la API, en /api, y el panel de administración, en /admin.

Genera los endpoints en el panel: Silence crea también los módulos de JavaScript para llamarlos en web/js/api/_auto/ (por ejemplo, import { photosAPI_auto } from "./api/_auto/photos.js";).
